# طرح پیاده‌سازی

**Stack** Python 3.12، کتابخانهٔ استاندارد، SQLite فایل‌محور و HTTP/JSON.

| جزء | مسئولیت |
|---|---|
| changeflow/__main__.py | خواندن پیکربندی هویت، راه‌اندازی پایگاه و سرور محلی |
| changeflow/api.py | Bearer، مسیریابی، JSON و وضعیت HTTP |
| changeflow/core.py | قواعد کاربرد، اعتبارسنجی محتوا و دسترسی، اجرای تراکنش و SQL پارامتری |
| tests/test_api.py | آزمون سیاه‌جعبه با HTTP واقعی روی loopback و بررسی SQLite مستقل |

برای یک موجودیت، کاربرد و دسترسی به داده در یک ماژول هستند. با اضافه شدن مورد کاربردی که نیاز مستقل به ذخیره‌سازی دارد، جداسازی بررسی می‌شود. مبنا [مدل داده](data-model.md)، [قرارداد](contracts/http.md) و [تصمیم‌ها](research.md) است. T001 باید پیش از گردش کاربرد تکمیل شود. T002 تا T004 فایل مشترک دارند و به‌ترتیب انجام می‌شوند.

هویت از نگاشت توکن به شناسه و نقش سمت سرور می‌آید. API هویت را استخراج می‌کند و لایهٔ کاربرد مجوز عملیات را با نقش و مالکیت بررسی می‌کند. تمام فرمان‌های روی رکورد به نسخه نیاز دارند. تراکنش نوشتن پیش از خواندن آغاز می‌شود تا ارزیابی وضعیت و نوشتن بر مبنای یک حالت سازگار انجام شوند.

معیار تکمیل پیاده‌سازی شامل عبور compilation و آزمون‌های واقعی، بررسی مرز API و کاربرد و ثبت موارد باز در Converge است. پذیرش تحویل با ارزیاب است.
